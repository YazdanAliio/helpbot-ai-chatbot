## 🧠 How the Chatbot Works

1. User enters a message  
2. Text is preprocessed (lowercase + punctuation removal)  
3. Input is matched with predefined intents  
4. Best response is selected randomly  
5. Default response is used for unknown queries  

> This approach demonstrates **basic AI intelligence** using rule-based NLP techniques.
